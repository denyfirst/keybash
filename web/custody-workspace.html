Open Servers

Protect your sign-in with your phone as well. Your servers stay closed until this is done. It takes about a minute.

  1. Open an authenticator app on your phone

    Google Authenticator, Microsoft Authenticator, Aegis or 2FAS all work.

  2. Scan the QR code

    Add a new account in the app and point the camera at the code.

    A password alone is not enough: this code makes sure only you set up this account's first factor.

    Can't scan? Enter the key by hand

    Choose "enter a setup key" in the app. Account: Keybash, type: time-based (TOTP).

    This QR code is your account's secret key: don't photograph or share it. It hides when you switch tabs.

  3. Enter the 6-digit code from the app

    The code changes every 30 seconds. Enter the current one.

Enter the code from your phone

Open your authenticator app and enter the 6-digit code it shows for Keybash.

Phone not at hand? Enter one of your recovery codes instead.

Save your recovery codes

They are shown only now. Each code works once, if your phone is lost. Keep them somewhere safe, apart from your phone.

A server is reachable only inside the networks set on the Keybash server. Nobody reaches it, administrators included, until it has an account with people on it, and each person signs in only as the accounts they are on. Its identity (SSH host key or RDP certificate) is pinned, and Keybash refuses the server if that changes until an administrator accepts the new one.

Update

Updating stops Keybash for a moment, so open sessions close. Your settings, people, servers and their accounts stay. The previous version is copied to /var/backups/keybash first and put back by itself if the new one does not start.

  1. In your Keybash checkout on the server (here ~/keybash), as your usual user, get the latest version and build it:

    Shell, as your user
    cd ~/keybash && git pull --ff-only && sh scripts/build-stage.sh ~/keybash-stage-$(git rev-parse --short HEAD)

  2. Install it, as root. It checks everything before it changes anything:

    Shell, as root
    cd ~/keybash && sudo sh scripts/upgrade.sh --stage=$HOME/keybash-stage-$(git rev-parse --short HEAD)

Until Keybash publishes signed releases, an update trusts the code GitHub serves over HTTPS. The same, step by step
